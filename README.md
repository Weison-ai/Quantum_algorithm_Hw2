# Homework 2

This project uses `uv` to manage the Python environment.

## 1) Setup environment with uv

```bash
# install dependencies and create .venv from pyproject.toml
uv sync

# activate the environment
source .venv/bin/activate
```

## 2) Launch Jupyter

```bash
uv run jupyter lab
```

Then open and run all cells in:

- `problem1.ipynb`
- `problem2.ipynb`
- `problem3.ipynb`
